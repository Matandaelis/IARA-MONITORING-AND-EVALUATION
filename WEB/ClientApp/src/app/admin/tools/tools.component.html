Seed Demo Project

Seeds a complete, deterministic Rural Health Program 2024-25 demo project: Demo Health Org, a Country → Region → District → Facility entity hierarchy, two years of monthly dates, five collected indicators and three calculated indicators (TOT, CPS, RATE), and 24 months of facility data.

Values are seeded through the real aggregation & calculation pipeline (SaveData → Aggregate → RunCalculations), so you can verify numeric accuracy in Entities, Indicators and Data. Re-running is safe (idempotent).

Requires the Administrator role. The seeded demo is used by the DemoProjectAccuracyTests suite to assert that every aggregated and calculated value matches hand-computed expectations.

Help: Import CSV File

The CSV file should contain the following headers:

  • Indicator: The values in this column should match the code of the indicator.
  • Entity: The values in this column should match the code of the entity.
  • Date: The values in this column should match the code of the date.
  • Value: The values in this column should represent the value for the given combination of indicator, entity and date. (Blank values are allowed)
  • Note: The values in this column will be stored in the note column for this data point. (Blank values are allowed)
